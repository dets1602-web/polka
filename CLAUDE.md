# «Полка» — своё приложение для книги ONYX BOOX Vasco da Gama 2

Проект Александра. Это главный экран электронной книги, который заменяет рабочий стол ONYX. Внутри:
- полки «Книги», «Схемы», «Документация»;
- файлы с Яндекс Диска по Wi-Fi;
- свои читалки PDF и MD;
- подсветка и Wi-Fi одной кнопкой;
- рамка во сне: картинка, дата и погода.

Пишем по-русски, коротко. Александр — монтажник ZONT и сервисник котлов, сам ставит APK на книгу.

## Книга (выяснено «Разведчиком», не по паспорту)
- **Модель:** Onyx MC_GAMA2, прошивка 1.8.3-mc от 2018-11-26.
- **Android 4.2.2, API 17** — не 6, хотя казалось иначе.
- **Железо:** Rockchip RK3026 (ARMv7), 512 МБ памяти.
- **Экран** 758×1024, сенсорный.
- **Подсветка Moon Light:** `/sys/class/backlight/rk28_bl/brightness` (0–255), приложение может туда писать.
- **Боковые кнопки** листают (`left_short=pageVolUp`, `right_short=pageVolDown`). Ловим `KEYCODE_PAGE_*`, `VOLUME_*` и `DPAD_LEFT/RIGHT`.
- **Память:** `/mnt/sdcard`. Книги ONYX лежат в `/sdcard/Books`.
- **Wi-Fi** ONYX выключает, когда книга засыпает.

## Сон и выключение ONYX (проверено на книге)
- **Оригиналы** в `/system/media` (только чтение): `standby0.png` … `standby4.png` (Васко да Гама и др.), `poweroff.png`, `nopower.png`. Все 1024×758, RGBA, повёрнуты на −90° (верх картинки смотрит влево).
- **Папка `/data/local/assets/images`** доступна приложению на запись без root. Файлы `standby0-4.png` и `poweroff.png` в ней перекрывают системные.
- **Файлы, созданные «Полкой», делать читаемыми для всех:** `setReadable(true, false)`. Иначе ONYX не может их открыть и показывает белый экран.
- **ONYX загружает картинку заранее.** Новая картинка сна или выключения показывается со второго засыпания или выключения.
- **Удалили наши `standby*.png`** — ONYX вернётся к своим картинкам.

## Сборка
- **Только GitHub Actions** (`.github/workflows/build.yml`). При push в `main` собирается `assembleDebug`, и релиз `latest` получает файл `Polka.apk`.
- **Локально собрать нельзя:** из облака нет доступа к dl.google.com и Maven.
- **Версии:** AGP 8.2.2, compileSdk 30, **minSdk 17**, targetSdk 22. Каждую версию повышаем: `versionCode` +1, `versionName` 0.N.
- **Подпись только v1**, ключ постоянный: `app/debug.keystore` (пароль `android`, alias `androiddebugkey`). Без постоянного ключа обновления не ставятся поверх («конфликтующая подпись»). Отпечаток SHA-256 начинается с `28:51:2D:3E`.
- **Библиотеки:** Conscrypt `2.5.2` (TLS 1.2/1.3 для GitHub и Яндекса на Android 4.2) и Pdfium `com.github.barteksc:pdfium-android:1.9.0`. ABI только `armeabi-v7a`.
- **dex должен быть один:** multidex на 4.2 не подключён. Следить за лимитом 64K методов.
- **Корневые сертификаты** лежат в `app/src/main/assets/certs`, дополняют системные.
- **Проверка после сборки:** скачать APK через `gh api repos/dets1602-web/polka/releases/assets/<id> -H "Accept: application/octet-stream"`. GraphQL и `gh release` в сессии запрещены, только REST. Проверить подпись, minSdk и что dex один.

## Как APK попадает на книгу
1. **Основной путь — по Wi-Fi:** «Приложения» → «Обновить «Полку»». Качает `releases/download/latest/Polka.apk` и открывает установщик.
2. **Через кабель**, если Wi-Fi-обновление сломано:
   - книга в режиме USB-накопителя видна на ПК как `E:\`;
   - класть в `E:\Download\Polka.apk` через `device_commit_files`;
   - stagedPath каждый раз брать с новым именем (`/mnt/user-data/outputs/Polka-0.N.apk`), иначе мост может отдать старый файл;
   - после записи забрать файл обратно (`device_stage_files`) и сверить SHA-256;
   - перед установкой: «Безопасное извлечение» и «Отключить USB-накопитель» на книге.
3. **Ссылку на APK Александру не присылать:** на книге её не скопировать.

## Яндекс Диск
- **Вход по коду:** `oauth.yandex.ru/device/code`, человек вводит код на `ya.ru/device`. Права только «Чтение всего Диска» (`cloud_api:disk.read`).
- **ClientID** `8cee5f8c6ddd4fc6af5699c169737d90` не секретный и лежит в `Yandex.java`.
- **Client secret** в код, репозиторий и чат не класть никогда. Его вводят на книге или кладут файлом `polka-secret.txt` в память книги. «Полка» забирает его во внутреннюю память и удаляет файл.
- **Папки на Диске:** `disk:/Полка/{Книги,Схемы,Документация}`, регистр букв не важен. «Книги» попадают в `/sdcard/Books`, остальные полки в `/sdcard/Полка/…`. Незнакомые папки и файлы прямо в «Полке» идут на полку «Книги».
- **Загрузка только скачивает,** ничего не удаляет. Размер сверяется. Пустые и недокачанные файлы скачиваются заново.
- **Безлимитные фото с телефона** лежат в разделе «Фото», а не в «Фотокамере». Для рамки решили их не брать.
- **Старый Android на ответ 401 бросает IOException** «No authentication challenges found». Это обработано в `Net.request`.

## Что где в коде (`app/src/main/java/ru/polka`)
- `HomeActivity` — главный экран, он же HOME:
  - часы и заряд, «Читаю сейчас», плитки полок и «Рамка»;
  - кнопки «Wi-Fi», «Яндекс Диск», «Приложения», «Свет», «Настройки».
- `FolderActivity` — папка полки: постранично, «сначала новые», то, что пришло одновременно, — по имени.
- `AppsActivity` — все приложения, «Настройки книги (ONYX)», «Старый рабочий стол ONYX», «Разведчик», «Обновить «Полку»».
- `PdfActivity` — PDF на Pdfium, без меню:
  - два пальца увеличивают и уменьшают, один палец двигает страницу;
  - свайп, тап по краю и боковые кнопки листают, двойной тап показывает страницу целиком;
  - «Назад» закрывает.
- `MdActivity` — MD и TXT: постранично, «Шрифт ±», меню по тапу в центр.
- `Frame`, `FrameActivity`, `FrameReceiver` — рамка во сне:
  - 60 своих картинок из `assets/frame`;
  - внизу дата и погода в Омске (Open-Meteo);
  - раз в час будильник меняет картинку, а при включённом Wi-Fi заодно забирает новое с Диска и погоду.
- `Light` — подсветка через sysfs.
- `Net` — Conscrypt, переадресации, `Authorization` только для хостов Яндекса.
- `Sync` — загрузка с Диска. Wi-Fi «Полка» сама не включает, решение Александра.
- `Yandex` — вход и API Диска.
- `Crash` пишет падения в `/sdcard/polka-crash.txt`, при разборе падения смотреть его.
- `ScoutActivity` («Разведчик») — диагностика: отчёт `/sdcard/razvedchik.txt`, тесты подмены картинок, подсветки, связи.

## Решения Александра (не нарушать)
- **Репозиторий публичный** (иначе кончаются минуты Actions). Трогаем только этот репозиторий.
- **Флибусту и OPDS не делать.**
- **Wi-Fi сам не включать:** только кнопкой на главном экране.
- **В читалке PDF меню не нужно,** увеличение пальцами.
- **На рамке не показывать, «что загрузилось»:** нужны картинки, дата и погода.
- **Не напоминать про время и сон.**
